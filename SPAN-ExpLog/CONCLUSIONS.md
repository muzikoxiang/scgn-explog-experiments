# SPAN-ExpLog 阶段性结论

更新日期：2026-09-09

## 一、核心结论

当前实验不支持“ExpLog 主干版优于参数匹配普通卷积增强器”的结论。

在 1k 冒烟实验中，SPAB 3 后加入 ExpLog 的 D 版本取得最高早期 PSNR，说明该模块可以正常训练，并具有一定的早期优化潜力。但随着实验扩展到 10k、3 个随机种子和 5 个独立测试集，参数匹配的普通卷积增强器 C 表现最好，且结论更一致。

DIV2K100 三随机种子的最终均值为：A `29.5484 / 0.8195`，C `29.7686 / 0.8215`，D `29.6619 / 0.8196`。C 相对 A 提升 `0.2202 dB / 0.0019 SSIM`；D 相对 A 仅提升 `0.1135 dB / 0.0001 SSIM`，并比 C 低 `0.1067 dB / 0.0018 SSIM`。更重要的是，D 相对 A 的 PSNR 只在 seed 10 上提高，在 seed 20、30 上均下降，平均增益受单个随机种子影响较大。

在 Set5、Set14、B100、Urban100 和 Manga109 上，C 的平均 PSNR 与 SSIM 均为三种方案最高。D 没有在任何独立测试集上超过 C；相对 A，D 在 Urban100 上 PSNR 下降，五个测试集的 SSIM 也均未超过 A。因此，当前最有泛化能力的改进是 C，而不是 D。

## 二、关于 ExpLog 的具体判断

1. **可训练，但对学习率敏感。** D 使用 `5e-4` 时后期性能回落；`2.5e-4` 更平稳但收敛偏慢；`3.5e-4` 在 seed 10 上最好。后续实验采用 `3.5e-4` 是有依据的，但也说明该结构的优化窗口较窄。
2. **插入更多位置不一定更好。** 1k 实验中，在 SPAB 2/4/6 或全部 SPAB 后加入 ExpLog 都没有超过单独放在 SPAB 3 后的版本，说明模块数量与效果不是单调关系。
3. **低方差不等于更优。** D 在三随机种子上的 PSNR 标准差最小，但均值低于 C，且相对 A 的提升只出现在一个 seed 上。现阶段只能说结果聚集得更紧，不能宣称其普遍更稳定或更可靠。
4. **额外非线性尚未转化为质量优势。** C 与 D 的部署参数量相同，D 只是在匹配结构上增加 ExpLog 非线性，但所有独立测试集都不如 C。这说明当前 ExpLog 形式不是额外容量之外的有效增益来源。

## 三、效率与工程判断

C 与 D 的部署参数量相同，均为 `0.4680 M`，比 A 增加约 `9.78%`。D 相对 C 的 Profiler FLOPs 几乎相同，但该统计没有完整计入 `exp`、`log`、`clamp` 和 `abs` 等逐元素运算，不能据此声称 ExpLog 计算开销只有约 `0.01%`。

实际测速中，D 相对 C 的平均延迟增加 `1.66%`，中位延迟增加 `2.39%`，峰值已分配显存增加 `3.37%`；但图像质量仍全面低于 C。因此从当前质量—效率权衡看，C 是更合理的工程版本，A 仍是速度和资源占用最低的版本。

## 四、可以用于汇报或论文的表述

> 在 SPAN 主干的第三个 SPAB 后加入轻量特征增强器能够改善 10k 训练预算下的超分辨率性能。三随机种子和五个独立测试集结果表明，参数匹配的普通卷积增强器取得了最一致的提升，而当前 ExpLog 非线性仅在短程训练和个别随机种子上表现出优势，未能在最终精度和跨数据集泛化上超过普通卷积对照。效率测试进一步表明，ExpLog 在参数量不变的情况下仍带来可测的延迟与显存开销。因此，现阶段结果支持“局部增强结构有效”，但不支持“ExpLog 非线性优于参数匹配卷积”的假设。

## 五、不建议使用的表述

- 不应写“ExpLog 在所有指标和数据集上均优于基线”。
- 不应将 1k 的最高 PSNR 当作最终效果结论。
- 不应仅根据 3 个 seed 的较小标准差写“ExpLog 显著提高稳定性”。
- 不应写“ExpLog 只增加 0.01% 计算量”，因为 Profiler 没有完整统计逐元素操作。
- 不应把 D 与 A/C 称为完全相同超参数的公平比较；D 使用了单独筛选出的学习率。
- 在没有显著性检验和更多随机种子前，不宜使用“显著优于”等统计学措辞。

## 六、下一阶段建议

### 如果目标是形成可用模型

选择 C 作为当前阶段版本。它在主验证集和五个独立测试集上表现最好，且比 D 更快、更省显存。

### 如果目标是继续研究 ExpLog

不建议直接把当前 D 扩展到 500k 长训练。应先修改模块，再做小预算筛选：

1. 给 ExpLog 分支增加可学习门控或较小的残差缩放，减少强非线性对主干特征的扰动。
2. 尝试更低成本、更平滑的变换，或减少 `exp/log` 的使用范围。
3. 继续以 C 作为必要的参数匹配对照，避免把额外参数带来的提升误归因于 ExpLog。
4. 对候选版本使用相同的超参数搜索预算，再进行多随机种子比较。
5. 只有新版本在多个独立测试集上稳定超过 C，才值得进入长训练和完整论文实验。

## 七、阶段性决策

- **工程主版本：C（Matched Conv）。**
- **研究结论：局部增强有效，但当前 ExpLog 公式没有证明优于普通卷积。**
- **ExpLog 后续策略：先重新设计，再扩大训练预算；不直接沿用当前 D 做长训。**
